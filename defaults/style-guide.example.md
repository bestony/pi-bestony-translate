# Style guide

- Audience: developers reading reference documentation; assume they know the CLI.
- Voice: second person, present tense, active voice. No exclamation marks.
- Headings: keep the source heading text when it is a command name or an identifier.
- Links: keep URLs unchanged; translate link text only.
- Numbers and units: keep the source form (KB, ms, v1.2.3).
- Lists and tables: keep the item order; do not merge or split rows.
